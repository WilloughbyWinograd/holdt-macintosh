# Shopping List

## Required To Operate The Computer Normally

1. Apple Desktop Bus keyboard cable.
   * Connector: four pin mini DIN male to male.
   * Purpose: connects the keyboard to the Macintosh SE.

2. Apple Desktop Bus mouse.
   * Purpose: basic Finder control and clock setup.
   * Any compatible Apple Desktop Bus mouse should be acceptable.

## Recommended Before File Work

1. External BlueSCSI v2 DB-25 for Macintosh.
   * Purpose: reversible external storage and boot images.
   * Reason: avoids opening the Macintosh at the first stage.
   * Use: boot a clean System disk, mount an archive image, copy the internal drive.

2. microSD card for BlueSCSI.
   * Purpose: holds the boot, archive, and clock disk images.
   * Keep the card and images backed up after the first successful copy.

## Service And Safety Items

1. Safe plan for Parameter Random Access Memory battery inspection.
   * The battery may be a 3.6 volt lithium battery on the logic board.
   * If it leaked, it can damage the board.
   * Do not touch the Cathode Ray Tube area unless properly prepared.

2. Long Torx driver and antistatic handling supplies, only if doing a careful internal inspection.
   * If there is any uncertainty, use a qualified vintage Mac repair person for the first opening.

## Not Recommended As The First Path

1. Modern USB floppy drive.
   * It generally cannot write 400 kilobyte or 800 kilobyte Macintosh disks.

2. Installing software directly on the internal hard drive.
   * Preserve the internal drive first.

3. Full remote control software as the first goal.
   * File based control is simpler and more reliable for a clock appliance.
