## Likely Ports To Use

The Macintosh SE normally uses Apple Desktop Bus for keyboard and mouse, and Small Computer System Interface (SCSI) for external storage.

The current working assumption is:

1. Keyboard connects with an Apple Desktop Bus cable.
2. Mouse is an Apple Desktop Bus mouse and can usually connect to the keyboard passthrough or another Apple Desktop Bus port.
3. BlueSCSI connects to the DB-25 external Small Computer System Interface port.

Confirm these with a full back panel photo before ordering anything unusual.
